## 哪些机房值得重点测：国内用户先看这四个

国内访客为主的场景，重点测香港 CN2 GIA、日本大阪软银、DC6 CN2 GIA-E、DC9 CN2 GIA 这四个机房。2021 年有第三方做过一轮全机房测速，当时的结论也是这四个国内表现最好，其中香港 CN2 GIA 延迟低、速度快、无丢包，评价是“除了贵没有缺点”，但它只随香港套餐提供，价格也确实贵一截。几年过去线路格局没有大变，这四个机房依然值得优先测，只是具体数值要以你当下的实测为准。

机房背后的线路差异决定了测速结果：

- **CN2 GIA**（DC6、DC9、香港、东京）：电信精品国际线路，电信联通双程 GIA，移动走 CMIN2，晚高峰最稳，也是价格最贵的一档。
- **CN2 GT / CN2**（DC2、DC3）：电信 CN2 网络但优先级低一档，DC3 的线路是电信 CN2 GT + 联通 4837 + 移动 CMI。有个容易踩的坑：**CN2 机房（如 DC3）的可用流量按常规机房的 1/3 计算**，同样标 1TB 流量，实际能用三分之一。
- **普通线路**（DC4、DC8、弗里蒙特、纽约、新泽西等）：价格便宜，适合访客在海外或对延迟不敏感的用途。普通 163 骨干线路晚高峰丢包并不罕见，测速时别只看白天数据。
- **联通荷兰 EUNL_9**：走联通 9929 精品线路，联通用户可以重点测。

一个参考判断：如果你的网站访客、客户主要在国内，CN2 GIA 的差价通常花得值；访问者全在海外，普通线路机房完全够用，没必要为用不上的线路付费。

## 常见问题

**搬瓦工机房测速地址是官方的吗？** 官方没有提供统一测速页面，测试 IP 和测速文件来自第三方收集整理，演示站点也是第三方自建的。数据仅供参考，最终以自己买后的实测为准。

**东京 CN2 GIA 没有测试 IP，怎么评估？** 只能买后实测。东京 CN2 GIA 属于高端套餐档位，成本不低，建议先用 GIA-E 套餐内的日本软银（JPOS_1，有测试 IP 185.212.59.222）估算日本机房的连通水平，确认需求后再升级。

**30 天退款是真的吗？** 是。官方知识库明确列出 30 天退款政策（30-day refund policy），和即时开通、在线率保证并列写在一起。买完测速觉得机房不合适可以申请退，这对“先测后用”的用户是实打实的保障，具体执行细节以下单页条款为准。

**被 DDoS 了怎么办？** 常规 KVM 线路被攻击时 IP 会被空路由（nullroute），需要自己套 Cloudflare 之类的防护，或者换到防护更好的 CN2 GIA-E 系列机房。换 IP 功能是收费的，大约 $8 一次。
